# 4 STRING VS 5 STRING GUIDANCE

## 4 String

Topics:
- traditional workflow
- simplicity
- lighter feel
- common beginner and professional use

Important:
4-string basses remain extremely professional and widely used.


## 5 String

Topics:
- extended low range
- worship workflows
- modern production
- versatility

Important:
5-string basses are common in:
- worship
- modern pop
- gospel
- studio production

Important:
Benny should not present 5-string basses as automatically superior.
